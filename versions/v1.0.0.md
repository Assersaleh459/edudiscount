# v1.0.0 — Initial Working Release

**Date:** 2026-05-19  
**Commit:** 6216c62

## What's in this version

Full-stack EduDiscount Portal running on Docker Compose.

### Student flow
- 3-step cascade selector: School → Subject → Teacher
- Price preview card (original price, discount %, final price) before requesting a code
- Email input → generates unique `EDU-{INITIALS}-{YEAR}-{RANDOM}` code
- Code display page with copy-to-clipboard and 48h expiry countdown

### Backend (Node.js / Express)
- PostgreSQL via Prisma ORM — all 5 models (AdminUser, School, Subject, Teacher, DiscountCode)
- Redis for code TTL caching
- JWT admin authentication
- Rate limiting: max 3 codes per email+teacher per 24h
- Async email (Nodemailer) + partner webhook (HMAC-signed)
- Mock partner receiver at `/api/mock-partner/receive`
- Lost code recovery: `POST /api/codes/resend`

### Admin dashboard
- CRUD for Schools, Subjects, Teachers
- Codes list with status filter + CSV export
- Reports: codes per school per month (bar chart), redemption rate per teacher
- Settings page (SMTP, partner API URL, webhook secret)

### i18n
- Arabic + English with RTL layout switching
- Fonts: Tajawal (AR) / Outfit (EN)

### Infrastructure
- Docker Compose: postgres, redis, backend, frontend, nginx
- Nginx reverse proxy: `/api/` → backend, `/` → frontend
- Production override: `docker-compose.prod.yml` (SSL-ready, no exposed ports)
- Seeded with 3 schools × 3 subjects × 2–3 teachers

## How to restore this version

```bash
git checkout v1.0.0
docker compose down -v
docker compose up --build
```
