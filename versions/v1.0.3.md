# v1.0.3 — Welcome Landing Page

**Date:** 2026-05-19

## What's new

- **Welcome page** added as the entry point (/) before the school selector
- Animated logo (configurable from Admin → Settings), title, and subtitle with a "Get Started" CTA
- **Admin Settings** now has a "Welcome Page" section:
  - Logo URL with live preview
  - Welcome Title (English + Arabic)
  - Welcome Subtitle (English + Arabic)
- Backend exposes /api/public/settings (no auth required) so the welcome page can read the configured values
- Routing: old / (SelectorPage) is now at /select; welcome page is the new /
